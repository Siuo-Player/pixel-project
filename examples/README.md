# Projetos de demonstração

Cada ficheiro `.pixelproj` pode ser importado através do botão **Importar** no Pixel Project. Os quatro exemplos foram desenhados primeiro como matrizes de preto, branco e transparência; as imagens coloridas são calculadas pelo motor ao abrir o projeto.

| Ficheiro | Origem | Interpretações |
|---|---:|---|
| `lighthouse-at-dusk.pixelproj` | 40×40 | 8 cores / 40×40, 12 cores / 24×24, 32 cores / 64×64 |
| `moonlit-cat.pixelproj` | 48×36 | 16 cores / 48×36, 8 cores / 24×18, 32 cores / 48×36 |
| `mushroom-grove.pixelproj` | 40×40 | 12 cores / 40×40, 4 cores / 20×20, 32 cores / 40×40 |
| `desert-temple.pixelproj` | 48×40 | 16 cores / 48×40, 12 cores / 24×20, 16 cores / 48×40 |

Os projetos usam combinações distintas de técnicas e dos três resolvedores. São bons pontos de partida para alterar parâmetros e comparar resultados sem redesenhar a imagem original.
